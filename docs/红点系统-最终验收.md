## 📋 完整逻辑链路

### 链路1：红点显示

```
【条件】
  ✅ 后端完成生成
  ✅ 订单状态 = completed
  ✅ 文档已保存到数据库
  ✅ 前端轮询检测到completed

【触发点】
  pages/writing/index.js:330行
  if (order.status === 'completed') { ... }

【执行动作】
  1. 刷新积分
  2. 更新底部状态："✅ 文档生成完成！"
  3. 保存状态到storage
  4. 设置标记：hasNewDocuments = true
  5. 设置数量：newDocumentsCount = X
  6. 调用API：wx.setTabBarBadge({ index: 1, text: 'X' })
  7. Toast提示："生成了X个文档"

【验证】
  ✅ 日志：[红点] ✅✅✅ TabBar红点设置成功: X
  ✅ TabBar：文档库Tab显示红色数字【X】
  ✅ Toast：显示成功提示
  ✅ 底部：显示完成状态
```

### 链路2：红点清除

```
【条件】
  ✅ hasNewDocuments = true
  ✅ TabBar有红点显示
  ✅ 用户点击文档库Tab

【触发点】
  pages/library/index.js:36行
  onShow() → loadDocuments()

【执行动作】
  1. 检查标记：hasNewDocuments = true?
  2. 日志：🔴 检测到新文档标记
  3. 加载文档列表
  4. 计算3分钟内文档
  5. 添加【新】标记
  6. 设置0.1秒定时器
  7. 0.1秒后执行：
     - 清除标记：hasNewDocuments = false
     - 移除红点：wx.removeTabBarBadge({ index: 1 })

【验证】
  ✅ 日志：[文档库] ✅✅✅ TabBar红点已清除
  ✅ TabBar：红点消失（0.1秒内）
  ✅ 【新】标记：继续显示
  ✅ storage：hasNewDocuments = false
```

### 链路3：防重复

```
【第1次进入文档库】
  hasNewDocuments = true
    ↓
  清除红点
    ↓
  设置 hasNewDocuments = false

【第2次进入文档库】
  hasNewDocuments = false
    ↓
  日志：ℹ️ 无新文档标记
    ↓
  不执行清除
    ↓
  正常显示文档（【新】标记基于时间）

【验证】
  ✅ 不会重复清除
  ✅ 不会报错
  ✅ 日志清晰
```
