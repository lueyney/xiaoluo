# 共识文档：个人中心页面重构

## 需求摘要
- 参考截图重构 `pages/profile` 视觉与结构。
- 顶部会员卡：头像、昵称、VIP等级、注册时间、积分余额、订单统计等。
- 快捷入口：余额、邀请好友、幸运转盘三列卡片。
- 模块：精彩活动卡（包含幸运转盘按钮）、邀请好友赚积分卡（显示邀请码、统计、按钮）、其他功能列表、退出登录。

## 验收标准
1. 结构与参考图一致，所有模块齐全。
2. 主色渐变、卡片阴影、圆角等视觉效果达成。
3. 积分/订单/生成文档等统计显示正确；文案与布局符合要求。
4. 按钮点击保持现有逻辑（弹 toast 或跳转），无报错。
5. WXSS 不含不支持语法；页面在微信开发者工具正常渲染。

## 技术方案
- WXML 重新布局：`header-card`、`quick-actions`、`activity-card`、`invite-card`、`feature-card`、`footer` 等组件化结构。
- JS：保留 `handleMenuClick` 等逻辑；新增字段（注册时间、统计数字、邀请码等）。
- WXSS：使用线性渐变、阴影、flex/grid；参照写作/订单页的风格维持一致。

## 边界
- 暂不实现真实活动/邀请接口；维持模拟数据与提示。
- 不调整其它页面。
