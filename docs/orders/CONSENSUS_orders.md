# 共识文档：订单页面重构

## 需求摘要
- 重构 `pages/orders` UI，采用截图中卡片式设计。
- 展示内容：顶部信息（标题、副标题、充值按钮）、统计卡组、状态 tabs、订单列表卡片。
- 列表逻辑：按照状态过滤展示，数据显示积分消耗、金额、完成时间等。

## 验收标准
1. 页面结构与截图一致，包含所需元素与布局。
2. 统计卡显示正确的数量：总订单、已完成、进行中、失败。
3. Tabs 切换时数据过滤准确；空状态显示提示。
4. 每条订单卡片包含：标题、副标题、积分变化、金额、状态标签、完成时间。
5. 充值按钮可跳转充值/个人中心（暂用 switchTab）。
6. 代码符合原生小程序规范，无语法错误，WXSS 不含不支持特性。

## 技术方案
- **结构**：重新编写 `index.wxml`，使用顶卡、统计 `summary-card`、`tab-bar`、`order-card` 等。
- **样式**：`index.wxss` 复制设计配色；浅色背景、圆角、阴影；按钮复用上下文样式（渐变、标签色）。
- **数据**：`index.js` 模拟订单数据，计算统计；状态映射增加“processing”等。
- **交互**：tabs 通过 `activeTab` 切换；充值按钮 `goToRecharge`；订单数据按状态过滤。

## 边界
- 不加入分页/下拉刷新。
- 不实现真实支付流程；pay/cancel/retry 可保留简化逻辑或提示。
- 不修改其他页面。
