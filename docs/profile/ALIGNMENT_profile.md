# 对齐文档：个人中心页面重构

## 项目上下文
- 原生微信小程序，已完成从 Taro 迁移。
- `pages/profile` 目前使用旧版卡片+菜单布局，风格与最新页面不一致。

## 新需求理解
- 目标如参考图：顶部渐变会员卡显示身份、VIP、注册时间、积分与统计。
- 下方卡片块展示：余额/邀请好友/幸运转盘快捷入口、精彩活动、邀请好友赚积分、其他功能列表、退出登录。
- 颜色体系：顶部紫-粉渐变，活动卡暖色等。
- 信息架构：保留积分、订单数、生成文档数等统计。
- 交互：按钮点击进入对应功能（现阶段可以弹提示或跳转存量逻辑）。

## 边界
- 样式完全重构；逻辑保持模拟数据，暂不接入真实接口。
- `tabBar`、“我的”路径保持不变。
- 参考图为视觉目标，需用 WXSS 实现。

## 疑问
- 活动卡、邀请卡按钮点击行为：暂按现有 `handleMenuClick` 内逻辑处理？
- 幸运转盘/邀请好友等入口是否需要具体界面？若无，保持 toast。
