## 🔧 技术实现

### 后端API

```
POST /api/coze/generate
Authorization: Bearer {token}

请求体:
{
  "topic": "论文题目",
  "field": "教育学",
  "contentTypes": ["学术论文"]
}

立即响应:
{
  "code": "PROCESSING",
  "message": "正在生成论文，请稍候...",
  "data": {
    "topic": "...",
    "creditsCost": 25,
    "estimatedTime": 30
  }
}

后台自动:
1. 调用Coze API
2. 生成960字论文
3. 扣减25积分
4. 保存到documents表
5. 发送完成通知
```

## 📊 数据流

```
用户输入
  ↓
前端提交
  POST /api/coze/generate
  {topic: "幼儿情绪调节能力培养的游戏化策略研究"}
  ↓
后端
  立即返回: "正在生成论文..."
  ↓
后台异步
  调用Coze API
  input: "幼儿情绪调节能力培养的游戏化策略研究"
  ↓
Coze流式返回
  chunk 1: "1.1 选题意义\n情绪调节能力..."
  chunk 2: ...
  拼接完整内容（960字）
  ↓
保存到数据库
  documents表:
    title: "幼儿情绪调节能力培养的游戏化策略研究"
    content: Coze生成的960字完整内容
    type: "学术论文"
  ↓
扣减积分
  user_credits: 570 - 25 = 545
  ↓
发送通知
  "论文生成完成"
  ↓
前端刷新文档库
  GET /api/documents
  ↓
显示新文档
  用户可查看、复制
  ↓
✅ 完成！
```
