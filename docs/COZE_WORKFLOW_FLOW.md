# Coze工作流详细说明

## 🔄 完整的数据流程

### 用户操作 → Coze API → 文档库

---

## 📝 Step 1: 用户在小程序中填写

```
AI创作页面:
  - 主题：游戏化学习促进幼儿情绪调节能力的实证研究
  - 学科领域：教育学
  - 生成类型：✓ 学术论文
  - 详细要求：需要包含实证研究方法
```

---

## 📡 Step 2: 提交到后端API

```javascript
POST /api/ai/writing

请求体:
{
  "field": "教育学",
  "topic": "游戏化学习促进幼儿情绪调节能力的实证研究",  // ← 论文题目
  "contentTypes": ["学术论文"],
  "requirements": "需要包含实证研究方法"
}
```

---

## 🤖 Step 3: 后端调用Coze API

```javascript
// Node.js代码
POST https://api.coze.cn/v1/workflow/stream_run

Headers:
  Authorization: Bearer cztei_liDpojPTsZcTjys472mGKBE5fChrIfNPEVOXvgCTa9uaPP3Tlg8iBQYcAo9ZW6SUy
  Content-Type: application/json

Body:
{
  "workflow_id": "7556513690260078628",
  "parameters": {
    "input": "游戏化学习促进幼儿情绪调节能力的实证研究"  // ← 论文题目作为input
  },
  "connector_id": "10000126"
}
```

**关键点**：
- ✅ `input` 参数 = 用户输入的论文题目
- ✅ Coze的workflow会基于这个题目生成完整的学术论文

---

## 📥 Step 4: Coze流式返回内容

```
流式响应（SSE格式）:

data: {"event":"Message","message":{"type":"answer","content":"#"}}
data: {"event":"Message","message":{"type":"answer","content":" 游戏化学习促进幼儿情绪调节能力的实证研究"}}
data: {"event":"Message","message":{"type":"answer","content":"\n\n## 摘要"}}
data: {"event":"Message","message":{"type":"answer","content":"\n本文通过实证研究..."}}
...
data: {"event":"Message","message":{"type":"answer","content":"## 结论\n..."}}
data: {"event":"Done"}
data: [DONE]
```

**我们的处理**：
```javascript
// 拼接所有content
fullContent = "#" + " 游戏化学习..." + "\n\n## 摘要" + "\n本文..." + ... + "## 结论\n..."

// 最终得到完整论文
fullContent = `
# 游戏化学习促进幼儿情绪调节能力的实证研究

## 引言
随着学前教育的发展...

## 研究方法
本研究采用准实验设计...

## 研究结果
数据分析表明...

## 结论
游戏化学习显著提升了幼儿的情绪调节能力...

## 参考文献
[1] ...
`
```
