# 共识文档：个人中心二级页面

## 需求摘要
- 为现有二级页面升级视觉（标题/副标题换行、间距优化）。
- 完善消息通知：展示充值、订单等关键事件，支持未读状态与红点提示。
- 新增幸运转盘页面，实现抽奖流程并可将结果写入通知列表。
- 保持帮助中心的搜索/分类功能，其他页面交互继续沿用。

## 验收标准
1. 二级页面标题/副标题分行展示，视觉符合设计。 
2. 消息通知页面列出关键事件，含未读字段；红点状态可随读取更新。 
3. 幸运转盘页面可随机奖励，并将结果追加到通知列表中。 
4. 其他页面原有功能保持可用。 
5. WXSS 符合小程序规范，无报错。

## 技术方案
- 调整现有页面排版，新增 CSS 控制标题换行与间距。
- 增强通知模块：扩展数据结构，提供未读标记、红点状态，新增写入函数供幸运转盘调用。
- 幸运转盘新增页面 `pages/profile/wheel`，使用随机奖励数组模拟抽奖，展示结果并写入通知。
- 继续使用本地存储或页面状态，保留后端对接点。

## 边界
- 消息数据与奖励为模拟实现，未接入真实推送。
- 幸运转盘使用简单动画/状态，无复杂物理效果。
- 在线客服仍为展示信息，不做实际跳转。
