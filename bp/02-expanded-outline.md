# 小珞 AI 融资 BP：扩展大纲

## 1. 封面｜不是另一个 AI 写作工具
- 主张：面向中文长文本的自然表达重构平台。
- 视觉：深色底、产品名、三条能力线：降重 / 去机械感 / 作者风格。
- 讲稿：论文是切入口，网文作者是长期高频用户，最终做内容生产基础设施。

## 2. 用户问题｜用户买的是“能交付的自然表达”
- 重复率下降但不能改错事实。
- AI 味降低但不能抹掉作者声音。
- 长文本处理不能破坏段落、章节和文档格式。
- 视觉：三个痛点环 + 一条交付结果线。

## 3. 市场迁移｜阶段性论文需求，长期作者需求
- 论文用户：刚需、付费明确、周期性。
- 网文作者：日更、高频、风格资产、迁移成本高。
- B 端：平台、工作室、出版和内容机构。
- 视觉：从论文到作者工作台再到 API 的箭头。

## 4. 产品｜小珞已经是一个工作台
- Web / 微信 / 抖音三端。
- 文本降重、DOCX 降重、AI 写作、文档库、支付积分。
- 工作流编排和运营后台。
- 视觉：能力矩阵。

## 5. 技术｜从模型调用升级为长文本重构管线
- 句级拆分与一对一替换。
- 前两句上下文约束，打散连续同构句式。
- V1 学术 / V2 小说 / 方案 A 逐句 / 方案 B 双句。
- 模型路由、流式回显、失败兜底、原格式 DOCX。
- 视觉：流水线图。

## 6. 朱雀闭环｜检测器不是口号，而是可回归的质量指标
- 构建人工原创、AI 原文、改写文本的样本集。
- 句级定位机械表达。
- 多候选生成 + 语义/风格/可读性筛选。
- 朱雀、多检测器、人工评分共同评估。
- 视觉：闭环圆环图，标注“自然表达改善”而非绝对通过。

## 7. 大厂为什么不会优先做
- 通用模型优先级高，垂直长尾策略优先级低。
- 降重/检测器场景存在品牌与合规敏感性。
- 高活跃低 ARPU 的作者群体需要长期陪伴。
- 交付工程（文档、队列、计费、审计）不是模型发布的主战场。
- 视觉：大厂通用层 vs 小珞垂直层对比。

## 8. 壁垒｜数据闭环比 Prompt 更难复制
- 真实长文本样本与失败案例。
- 朱雀评测数据和策略版本。
- 作者风格画像、词库、人物与世界观。
- 长文本工作流和文档交付。
- 视觉：四层护城河。

## 9. 已验证基础｜产品、流量、商业化链路都已存在
- 50w 注册、2.6w DAU 峰值、9% 付费转化（待尽调证据）。
- 1 亿+ token 多模型评测。
- 扣子付费排名 TOP4。
- 话本小说 AI 美化使用率 16%→41%。
- 视觉：四个大数字 + 证据标签。

## 10. 商业模式｜一次性刚需 + 高频订阅 + B 端 API
- 个人按量：低门槛。
- 作者订阅：月度字数、风格档案和长篇能力。
- 工作室 / 平台：API、私有化、质量控制台。
- 视觉：三层收入金字塔。

## 11. 增长｜先验证 100 名作者，再放大
- 100 名真实作者、30 天实验。
- 观察周频、月均字数、留存、付费、人工节省时间。
- 作者社群、平台合作、内容营销、邀请裂变。
- 视觉：90 天实验时间轴。

## 12. 里程碑｜12 个月做成作者工作台
- 0-3 月：朱雀评测集、100 作者实验、风格档案 MVP。
- 4-6 月：订阅产品、长篇上下文、作者社群渠道。
- 7-12 月：工作室 API、平台试点、多检测器回归。
- 视觉：三段路线图。

## 13. 融资用途｜把产品能力变成可规模化资产
- 40% 数据与评测。
- 30% 作者产品和模型基础设施。
- 20% 增长与渠道。
- 10% 合规与安全。
- 视觉：环形分配图。

## 14. 结尾｜从降重工具到中文长文本基础设施
- 论文带来现金流，作者带来粘性，平台带来规模。
- 小珞的长期目标：让 AI 生成的内容重新拥有具体作者感。
- CTA：融资用于验证作者订阅和 B 端复制。
