# 对齐文档：登录页面优化

## 项目上下文
- 已完成小程序原生化，登录页当前为基础渐变+卡片风格，整体泛蓝色，模块线性排列。
- 功能：手机号 + 验证码登录、获取验证码、快速测试登录、功能介绍模块。
- 交互逻辑已实现（校验手机号、倒计时等），主要任务是视觉/UI 提升。

## 需求理解
- 目标：参考整体品牌风格（蓝紫渐变、卡片阴影），打造更具品牌感、更加沉浸式的登录体验。
- 关键区域：
  1. 顶部品牌展示（logo、标题、slogan）。
  2. 登录表单（手机号、验证码、验证码按钮、登录按钮）。
  3. 协议提示。
  4. 功能亮点展示。
- UI 优化方向：更丰富的背景层次、立体感卡片、按钮渐变、精细化排版、图标/插画提升。

## 边界
- 不改变现有交互逻辑（手机号验证、倒计时、快速登录等）。
- 仍采用手机号+验证码登录方式；暂不加入第三方登录。
- 图片资源可使用在线占位图或 SVG/emoji，后续可替换为正式素材。

## 疑问
1. 是否有品牌色/插画参考或需统一到其他页面的设计语言？
2. 功能亮点模块是否需要可点击跳转？目前为静态介绍。
3. 是否需要适配深色模式或无障碍（大字号）？
4. 是否需要在表单下方增加客服/帮助入口？
