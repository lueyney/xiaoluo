# 共识文档：AI降重页面改造

## 一、需求概要
- 将 `pages/rewrite` 页面 UI 和交互重构为最新设计：顶部 info 卡片、优势模块、降重设置卡片、输入区域、底部操作与提示。
- 保留现有降重业务逻辑（积分计算、流程、结果展示）。
- 新增的设置项（学科领域、语言类型、降重模式开关、检测平台）需提供可选项与状态同步，但在当前迭代中仅用于 UI 呈现，不影响降重算法。

## 二、验收标准
1. 页面结构符合截图展示的层级和布局：顶部 info 卡、三项优势、设置卡片、输入卡片、底部按钮与提示。
2. 样式遵循项目规范：卡片圆角、阴影、渐变按钮、背景色与间距与设计匹配；使用 WXSS 合法语法（无 `@media`、无复杂组合选择器）。
3. 交互逻辑：
   - 选择学科、语言、检测平台、降重模式开关均可更新界面状态。
   - 文本输入时自动计算字数与预计积分，逻辑与先前一致。
   - 按钮状态随字数、积分是否足够以及加载状态变化。
   - 降重流程（进度条、结果展示、保存、复制等）保持可用。
4. 无控制台错误与语法异常；真机调试不出现 `Unexpected token` 等问题。

## 三、技术方案
- 重写 `index.wxml`：采用块级结构，定义头部卡片、优势 `feature-card`、`settings-card`、输入卡片、按钮与Tips。
- 更新 `index.wxss`：统一背景浅色渐变，卡片使用白色+阴影；按需定义新类名（如 `.info-card`, `.feature-group`, `.setting-list` 等）。
- 调整 `index.js`：
  - 新增数据：`disciplines`, `languages`, `platforms`, `modeEnabled` 等。
  - Methods：`onDisciplineChange`, `onLanguageChange`, `onPlatformChange`, `toggleMode` 等。
  - 现有 `updateExpectedCost` 按当前逻辑运作，可基于模式开关微调文案（不改计算公式）。
- 保持 `startRewrite`、`completeRewrite` 等核心逻辑。

## 四、任务边界
- 不修改后端/接口；不增加新的网络请求。
- 不引入新组件库；全部使用原生组件。
- 不调整 `app.json`、tabBar 等全局配置。

## 五、质量保证
- 手动检查：构建后在开发者工具查看视觉效果、功能交互。
- 校验：文本输入、切换设置、降重流程、结果动作、保存/复制均可操作。
- 代码规范：使用 `rpx` 单位、保持文件命名与结构规范、无多余控制台日志。

## 六、后续工作
- 若需将设置项影响降重算法，可在后续迭代增加逻辑。
