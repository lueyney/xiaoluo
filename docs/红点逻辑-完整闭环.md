# 红点逻辑 - 完整闭环方案

## 🎯 核心需求

**正确的逻辑顺序：**
1. ✅ 用户生成文档
2. ✅ 后台处理（30-120秒）
3. ✅ **文档生成完成后** → 显示红点
4. ✅ 用户点击文档库Tab
5. ✅ 进入文档库
6. ✅ **0.1秒内**红点消失

---

## 📊 完整状态机

```
[提交] → [生成中] → [完成] → [显示红点] → [用户查看] → [清除红点]
   ↓         ↓          ↓          ↓            ↓            ↓
 无红点    无红点      无红点    有红点【N】   有红点      无红点
   ↓         ↓          ↓          ↓            ↓            ↓
 轮询      轮询      轮询停止   保持显示      0.1秒      完成
```

    ↓

    ↓

```

### 阶段2：后台生成（30-120秒）
```
后端Coze生成文档
    ↓
前端轮询（每10秒）
    ↓

    ↓
响应：{ status: "processing" }
    ↓

    ↓

    ↓

```

    ↓
保存文档到数据库
    ↓

    ↓

    ↓

    ↓

    ↓

    ↓
✅ TabBar文档库Tab显示红点【X】

```

✅ TabBar红点消失

### 闭环3：防重复提示
```
第一次进入文档库：
  hasNewDocuments = true
  → 显示【新】标记
  → 0.1秒后清除红点
  → 设置 hasNewDocuments = false
  
第二次进入文档库：
  hasNewDocuments = false
  → 不清除红点（因为本来就没有）
  → 如果文档在3分钟内，仍显示【新】标记
  
第三次进入文档库（超过3分钟）：
  hasNewDocuments = false
  → 不清除红点
  → 文档超过3分钟，不显示【新】标记
  → 完全正常状态
```

## 🔍 核心代码逻辑

### 1. 生成完成时设置红点
**文件：** `pages/writing/index.js` (行330-366)

```javascript
if (order.status === 'completed') {
  // 1. 刷新积分
  points.syncCreditsFromServer();
  
  // 2. 获取文档数量
  const docCount = this.data.lastGenerateCount || 1;
  
  // 3. 更新底部状态
  this.setData({
    generatedContent: '✅ 文档生成完成！',
    generateState: 'completed'
  });
  
  // 4. 保存完成状态
  wx.setStorageSync('lastGenerationStatus', { ... });
  
  // 5. 设置红点标记
  wx.setStorageSync('hasNewDocuments', true);
  wx.setStorageSync('newDocumentsCount', docCount);
  
  // 6. 显示TabBar红点
  wx.setTabBarBadge({
    index: 1,
    text: String(docCount),
    success: () => console.log('✅✅✅ 红点设置成功')
  });
  
  // 7. Toast提示
  wx.showToast({ title: `生成了${docCount}个文档` });
}
```

**关键点：**
- ✅ 只在检测到 `status === 'completed'` 后执行
- ✅ 使用保存的 `lastGenerateCount`
- ✅ 详细的日志输出

### 2. 进入文档库清除红点
**文件：** `pages/library/index.js` (行98-122)

```javascript
// 检查标记
const hasNewDocs = wx.getStorageSync('hasNewDocuments');

if (hasNewDocs) {
  console.log('[文档库] 🔴 检测到新文档标记');
  
  // 0.1秒后清除
  setTimeout(() => {
    wx.setStorageSync('hasNewDocuments', false);
    wx.removeTabBarBadge({ index: 1 });
    console.log('[文档库] ✅✅✅ TabBar红点已清除');
  }, 100);
}
```

**关键点：**
- ✅ 只在 `hasNewDocuments === true` 时执行
- ✅ 0.1秒（100毫秒）后清除
- ✅ 清除标记防止重复

### 3. 【新】标记显示
**文件：** `pages/library/index.js` (行70-86)

```javascript
// 检测3分钟内的文档
const now = new Date().getTime();
const recentDocs = docs.filter(doc => {
  const docTime = new Date(doc.created_at).getTime();
  return now - docTime < 180000; // 180秒 = 3分钟
});

// 添加isNew标记
const docsWithNewMark = docs.map(doc => ({
  ...doc,
  isNew: recentDocs.some(rd => rd.id === doc.id)
}));
```

**关键点：**
- ✅ 基于创建时间判断
- ✅ 3分钟内显示【新】
- ✅ 与红点独立，持续时间更长

## 🐛 边界情况处理

### 情况1：轮询失败
```
问题：网络中断，无法检测到completed
解决：失败3次后停止，显示提示
结果：用户手动刷新文档库即可
```

### 情况2：快速切换
```
问题：用户在0.1秒内多次切换
解决：每次进入都检查hasNewDocuments
结果：只清除一次，不会出错
```

### 情况3：多窗口
```
问题：用户打开多个小程序实例
解决：每个实例独立的storage
结果：互不影响
```

### 情况4：文档删除
```
问题：用户删除了新文档
解决：【新】标记基于时间，不基于ID
结果：不受影响
```
