# 共识文档：登录页面优化

## 需求摘要
- 以品牌蓝紫渐变打造沉浸式登录体验，增强视觉层次与信任感。
- 模块：
  1. 顶部品牌库：logo、标题、副标题、渐变背景。
  2. 登录表单卡片：手机号、验证码、倒计时按钮、登录按钮。
  3. 协议提示。
  4. 功能亮点/优势模块。
- 目标实现：更强的视觉吸引、良好的对比度、统一的渐变按钮与卡片风格。

## 验收标准
1. 页面背景采用多层渐变/光影，顶部品牌区域突出。
2. 登录表单卡片具备立体感（阴影、玻璃拟态或柔光效果），按钮使用统一渐变。
3. 验证码按钮禁用态、倒计时样式清晰可辨；登录按钮有加载态。
4. 协议提示、功能亮点布局整齐，图标/emoji 风格统一。
5. WXSS 不包含不支持的语法，页面在开发者工具无报错。

## 技术方案
- WXML：调整结构，加入背景层 (装饰圆/渐变)、表单卡片内部布局优化、亮点模块使用分组卡片。
- WXSS：使用线性渐变、模糊、阴影、玻璃质感；统一按钮样式 `primary-btn`、`outline-btn`，状态色明确。
- 交互逻辑：延用现有 JS，不做改动，仅若需提示文案微调。

## 边界
- 不新增登录方式、接口或后端逻辑。
- 图片可使用现有网络图，后续可替换。
- 若无品牌规范，按当前项目蓝紫主色展开。
