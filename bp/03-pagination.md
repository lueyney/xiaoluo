# 小珞 AI 融资 BP：分页稿

|---|---|---|---|
| 1 | Title | 小珞 AI | 让 AI 生成的内容，重新拥有具体作者感 |
| 2 | Problem | 用户买的不是“改几个词” | 他们要的是自然、准确、保留风格、可直接交付 |
| 3 | Market | 从阶段性论文需求，到高频作者工作流 | 论文切入 → 网文作者 → 内容机构 API |

| 12 | Roadmap | 12 个月成为作者工作台 | 评测集 → 订阅 → API |
