### 3. 文档库页面优化

**文件：** `pages/library/index.js`

**核心逻辑：**

#### 1. 加载时检测新文档
```javascript
onShow() {
  // 记录查看时间
  docNotifications.updateLastViewTime();
  this.loadDocuments();
}

loadDocuments() {
  // 获取所有文档
  const docs = await syncDocumentsFromServer();
  
  // 检测新文档（最后查看之后创建的）
  const lastViewTime = docNotifications.getLastViewTime();
  const newDocs = docs.filter(doc => {
    const docTime = new Date(doc.created_at).getTime();
    return docTime > lastViewTime;
  });
  
  // 添加新文档通知
  if (newDocs.length > 0) {
    docNotifications.addNewDocuments(newDocs.map(d => d.id));
  }
  
  // 给文档添加isNew标记
  const docsWithNewMark = docs.map(doc => ({
    ...doc,
    isNew: newDocs.some(nd => nd.id === doc.id)
  }));
  
  // 延迟清除红点（让用户看到）
  setTimeout(() => {
    docNotifications.clearAllNewDocuments();
  }, 500);
}
```

#### 2. WXML添加【新】标记
```xml
<view wx:if="{{item.isNew}}" class="doc-card__new-badge">
  <text>新</text>
</view>
```

#### 3. WXSS样式设计

## 🔄 完整工作流程

```
用户生成文档
    ↓
AI创作页面：显示"正在生成中..."
    ↓
后台轮询检查状态（每10秒）
    ↓
生成完成
    ↓
AI创作页面：显示"✅ 文档生成完成"
    ↓
用户切换到【文档库】Tab
    ↓
检测新文档（基于时间戳）
    ↓
TabBar显示红点数字 + 文档卡片显示【新】标记
    ↓
0.5秒后自动清除TabBar红点
    ↓
【新】标记保留（下次刷新消失）
```

## ✨ 红点逻辑特性

### 1. 时间戳判断机制

- ✅ 【新】标记在下次刷新时消失
- ✅ 不需要手动操作

## 🐛 Bug预防

### 1. 红点重复出现
**预防：**
- ✅ 基于时间戳而非文档ID列表
- ✅ 进入文档库时更新lastViewTime
- ✅ 清除红点时完全清空列表

### 2. 新标记不消失
**预防：**
- ✅ isNew基于lastViewTime动态计算
- ✅ 每次加载重新判断
- ✅ 不持久化isNew状态

### 3. 轮询不停止
**预防：**
- ✅ 设置最大尝试次数（20次）
- ✅ 页面卸载时清理定时器
- ✅ 完成或失败后立即停止

### 4. 状态不同步
**预防：**
- ✅ 完成后立即刷新积分
- ✅ 使用统一的docNotifications模块
- ✅ TabBar和文档库状态一致
