# 对齐文档：订单页面重构

## 项目上下文
- 技术：原生微信小程序，Page/WXML/WXSS。
- 现状：`pages/orders` 仍为早期风格（紫色背景、统计块、订单卡片），与最新设计不匹配。

## 需求解读
- 目标：将订单页面改造成截图中展示的样式。
- 关键元素：
  - 顶部信息卡（标题、副标题、充值按钮）。
  - 四个统计概览（总订单、已完成、处理中、失败）。
  - Tabs（全部、已完成、进行中、失败）。
  - 订单卡：图标、标题、副标题、积分、金额、标签、完成时间等。
- 功能逻辑：tabs 切换过滤订单；模拟数据即可。

## 边界
- 不接入真实接口；仍使用前端模拟数据。
- 不改变订单状态处理逻辑，只调整结构与字段含义。
- 保持导航栏标题、tabBar 配置不变。

## 疑问
- 订单状态枚举：按照截图理解为「已完成」「处理」「失败」，新增“进行中”状态用于展示。
- 充值按钮行为：目前可跳转到充值相关页面（暂用 switchTab 到 profile 或留提示）。
