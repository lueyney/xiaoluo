# 多文档同时生成功能

## 🎉 功能说明

当用户在AI创作页面选择**多个文档类型**时（如：学术论文 + 开题报告 + 任务书），系统会自动为每个类型创建独立的文档，方便用户在文档库中分别查看和管理。

---

## ✅ 功能特点

### 1. 自动拆分
- 用户选择多个类型
- 系统自动为每个类型创建独立文档
- 每个文档都有独立的标题和类型标签

### 2. 智能命名
```
主题: "人工智能研究"
选择类型: 学术论文、开题报告、任务书

生成结果:
  - 人工智能研究 - 学术论文 [学术论文]
  - 人工智能研究 - 开题报告 [开题报告]
  - 人工智能研究 - 任务书 [任务书]
```

### 3. 积分分配
- 总积分平均分配到每个文档
- 例如：总计75积分，3个文档，每个25积分

---

## 🔄 工作流程

### 用户操作流程

```
1. 选择主题："深度学习算法研究"
   ↓
2. 选择多个类型：
   ✓ 学术论文（35积分）
   ✓ 开题报告（25积分）
   ✓ 任务书（15积分）
   ↓
3. 点击"开始生成"
   ↓
4. 消耗总积分：75积分
   ↓
5. 生成内容
   ↓
6. 自动保存3个独立文档：
   - 深度学习算法研究 - 学术论文
   - 深度学习算法研究 - 开题报告
   - 深度学习算法研究 - 任务书
   ↓
7. 在文档库查看：显示3个独立文档 ✅
```

### 技术实现流程

```javascript
async saveDocToStorage(content) {
  const contentTypes = ["学术论文", "开题报告", "任务书"];
  const topic = "人工智能研究";
  
  // 检查是否有多个类型
  if (contentTypes.length > 1) {
    // 计算每个文档的积分
    const costPerDoc = Math.ceil(totalCost / contentTypes.length);
    
    // 为每个类型创建独立文档
    for (let type of contentTypes) {
      await documents.createDocument({
        title: `${topic} - ${type}`,
        content: content,
        type: type,
        field: field,
        creditsCost: costPerDoc
      });
    }
  }
}
```

## 📝 代码改进

### 1. 多文档保存逻辑

```javascript
// 改进前：只保存一个文档
saveDocToStorage(content) {
  const doc = {
    title: topic,
    type: contentTypes.join("、"),  // "学术论文、开题报告"
    content: content
  };
  createDocument(doc);  // 保存1个文档
}

// 改进后：分别保存每个文档
async saveDocToStorage(content) {
  if (contentTypes.length > 1) {
    // 为每个类型创建独立文档
    for (let type of contentTypes) {
      await createDocument({
        title: `${topic} - ${type}`,  // 独立标题
        type: type,                   // 独立类型
        content: content
      });
    }
  }
}
```
